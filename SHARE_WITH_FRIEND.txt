NOIR LANGUAGE RIDDLES: THE BABEL CONSPIRACY
===========================================

Berlin, 1947. A linguist has disappeared. Solve etymological riddles,
follow the leads across the city, and work out where Elena is being held.


HOW TO RUN (LINUX)
------------------
You got a single file called "NoirRiddles". No Python needed.

  1. Open a terminal in the folder with the file
  2. Make it executable:   chmod +x NoirRiddles
  3. Run it:               ./NoirRiddles

Make the terminal window big (at least 100 columns x 30 rows) BEFORE starting,
to get the full-screen ASCII art version. In a smaller window the game starts
in a plain console mode instead.


WINDOWS OR MAC?
---------------
The Linux file won't run there. Either:
  - Ask Alex for a build made on your system, or
  - Install Python 3.9+, then in the game folder run:
        pip install -r requirements.txt
        python play.py


CONTROLS
--------
  1-4    answer              h   hint
  Enter  continue            g   follow a new lead
  e      evidence            n   case notes
  b      notebook            t   travel
  v      confront Volkov     m   menu (save / load)

Some riddles want a typed answer: type it and press Enter (Esc gets you
back to the single-key commands).

Tips: guessing doesn't work, wrong answers get swapped for new ones.
Show your evidence to people. Keep some for Volkov.
Read your case notes before you face him.


SAVE FILES
----------
The game autosaves. Choose "Continue" on the title screen to pick up again.
Saves live in:
  Linux/Mac: ~/.babel_conspiracy_saves/
  Windows:   %USERPROFILE%\.babel_conspiracy_saves\
